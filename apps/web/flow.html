The three faces

One key. Three services.

The same OpenAI-shaped endpoint family. The customer picks the face by model — a real name for text, or the service names search and image.

Text

OpenAI-compatible chat, streaming or not. The model is a real name from your account’s verified list — e.g. gemini-2.5-flash.

Search

model:"search" → normalized web results, one shape no matter who answered. The search legs pool like any other key.

Image

model:"image" → a JPEG, measured like everything else. Monthly image grants live in the same limits matrix.

How a client uses your key

Three steps. One copy-paste.

Everything a customer does with a Jatin key — from the moment it is issued to the first token back.

Issue the key

Dashboard → Flow → Keys → Issue a gateway key. Pick a name — mobile-app, ci, a partner — and the key is minted as jkn_…. It is shown exactly once; there is no read path that returns it again, so the client copies it now.

Point any client at the gateway

No SDK rewrite. Any OpenAI-compatible client works — set the base URL to https://<your-gateway>/api/flow, put the key in the Authorization header, and you are in. Plain HTTP works identically.

Call by name

model is one of the real names on the client’s Models tab — each checked daily against the catalog — plus search and image. The client never sees which provider answers. When the account’s limit is reached the gateway answers 429 with a retry hint; every number is measured.

first call — text
curl https://<your-gateway>/api/flow/chat/completions \
  -H "Authorization: Bearer jkn_…" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-2.5-flash","stream":false,"messages":[{"role":"user","content":"hi"}]}'
import OpenAI from "openai";

const ai = new OpenAI({
  baseURL: "https://<your-gateway>/api/flow",
  apiKey:  "jkn_…",
});

const r = await ai.chat.completions.create({
  model:    "gemini-2.5-flash",   // any verified name · "search" · "image"
  messages: [{ role: "user", content: "hi" }],
});
console.log(r.choices[0].message.content);
from openai import OpenAI

ai = OpenAI(
    base_url="https://<your-gateway>/api/flow",
    api_key="jkn_…",
)

r = ai.chat.completions.create(
    model="gemini-2.5-flash",   # any verified name · "search" · "image"
    messages=[{"role": "user", "content": "hi"}],
)
print(r.choices[0].message.content)

The search and image faces ride the same key: POST /api/flow/search with {"query":"…"} and POST /api/flow/image with {"prompt":"…"}.

The limits desk

Grants carved from real capacity.
