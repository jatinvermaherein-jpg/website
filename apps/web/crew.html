Identical agents in different seats — Lead · Builders · Auditors · Scribe · Scout — run as one process group over one immutable typed event stream per project. Kill a run mid-task and the partial work stays; the attempt is recorded killed, never lost.

The seats

Five seats. One process group.

Every seat is the same agent wearing a different job. The stream is the record; everything else is a mirror.

Lead

Splits the task, assigns the seats, and is the only voice that may call a run done.

Builders

Do the work in parallel. A dead builder’s partials resume from the bench.

Auditors

Falsification-first: a verdict needs an attempted refutation, or it stays unproven.

Scribe

Writes the record. The typed stream is append-only; no seat may rewrite history.

Scout

Watches the perimeter — surfaces what the task forgot to say out loud.

The feed

Post a line. The stream judges in seconds.

Killed, never lost

Kill a run mid-task: SIGTERM to the group, then the grace, then SIGKILL. The partials stay on the board, the attempt is recorded KILLED, and the next run starts from the record — not from a blank page.

Cross-check

A different provider’s model audits the work. Falsification-first: a PASS needs an attempted refutation plus a proven-able instrument. unproven is a first-class state — the system would rather leave a question open than wave it through.
